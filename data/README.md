# Dataset Directory

## RT-IoT2022 Dataset

Place the RT-IoT2022 dataset CSV file in this directory.

### Download Instructions

1. Visit the UCI Machine Learning Repository:
   https://archive.ics.uci.edu/dataset/942/rt-iot2022

2. Download the dataset.

3. Extract the CSV file and place it here as:
   ```
   data/RT_IoT2022.csv
   ```

4. The file should contain approximately 123,117 records with network traffic
   features and an `Attack_type` target column.

### Expected File
```
data/
└── RT_IoT2022.csv
```

### Note
The dataset is not included in the repository due to its size.
Please download it directly from the UCI repository.
